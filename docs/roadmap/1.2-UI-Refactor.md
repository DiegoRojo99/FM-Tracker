## FM27 Companion UI Pilot
- The shared theme uses the [official FM27 foundation palette](https://brand.footballmanager.com/colour): Midnight `#0A0F1E`, Twilight `#6E0FD7`, Horizon `#AF78FF`, Cloud `#D2C8F5`, and Air `#E6E6FA`.
- Highlight Pink is `#FF0073`; Highlight Violet is `#BF00FF`. Midnight remains the dominant background, with accents reserved for actions and selection. Supporting surface and status colours are application tokens, not official brand swatches.
- Adobe `.ase` files contain swatches; the web app uses hex values directly in [globals.css](../../src/app/globals.css) and does not need to load these files.
- The Saves pilot uses flat panels, compact club/season cards, a separate league/delete footer, matching loading skeletons, and visible keyboard focus states. Filtering, sorting, onboarding, and deletion behavior remain unchanged.
- Primary actions use a horizontal Highlight Pink to Highlight Violet gradient with sRGB interpolation. White text is retained by design preference; it does not meet WCAG AA contrast for small text across the entire gradient. Destructive actions retain their red gradient.
- Official logos are not introduced by this pilot. Confirm applicable usage permissions before publishing them; FM Tracker retains its own identity.
- The companion styling now covers Add Save, save details (career, seasons, honours and challenges), Challenges and their goal view, Trophies, Login, landing, Profile and Friends (feed, lists, requests, search and leaderboard). Matching skeletons and the shared modal shell use the same flat surfaces.
- Shared classes in `globals.css`: `fm-panel` for main panels, `fm-inset` for nested cards, `fm-field` for inputs, `fm-action` for gradient actions, `fm-secondary` for secondary controls and `fm-choice` for selections driven by `aria-pressed`. Controls have visible keyboard focus and a minimum 44px height.
- Existing data fetching, filters, ownership checks, wizard steps and mutation flows are preserved. Navigation remains unchanged; a sidebar is outside this rollout.
