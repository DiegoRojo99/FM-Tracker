# 2.5 FM27 Integration Roadmap

**Status:** Planning
**Last Updated:** 2026-11-06
**Target Completion:** Q1 2027

## Overview

This roadmap defines the strategy for integrating Football Manager 2027 (FM27) game version into FM-Tracker. FM27 represents the 2026/27 season in Football Manager and includes updated team rosters, competitions, and leagues.

The app already supports multi-game versions (FM24, FM25, FM26) with a progressive data pipeline for competitions, teams, and gender-aware league filtering. FM27 integration will follow the established patterns while adding the latest season data and validating against evolving game structures.

---

## Technical Considerations

### Database Schema
- Reuse existing `Save`, `Competition`, `Team`, `Trophy`, `Season` models
- No new models required for FM27 support
- Ensure `gameId` field is consistently used as discriminator

### API Integration
- Validate API schema matches FM26 (no breaking changes expected)
- Implement retry logic for data import failures
- Cache API responses to avoid rate limiting

### Data Migration Path
- Zero-downtime deployment (add FM27 as new option, don't modify existing data)
- Backward-compatible database queries
- Gradual data import (can import competitions in batches)

### Performance
- FM27 data addition should not impact existing FM26 query performance
- Monitor N+1 queries when fetching saves with games
- Consider data partitioning if dataset grows significantly
