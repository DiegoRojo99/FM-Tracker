# 2.5 FM27 Integration Roadmap

**Status:** In Progress
**Last Updated:** 2026-11-06

## Scope

- Discuss and approve each subphase before execution.
- Retain FM26 playable domestic leagues; add Saudi Pro League (men) and Arkema Première Ligue (women).
- Import team records and league-season memberships only; no players, rosters, squads, or transfers.
- Do not source teams from cups, continental competitions, or transition tournaments.
- Preserve existing coordinates when the API omits them.
- Validate dev before applying to prod; sync the shared Algolia index from prod only.
